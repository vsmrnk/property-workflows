# 0004. AI-парсинг документа: AI SDK + OpenRouter (безкоштовні моделі) + zod

- Статус: прийнято
- Дата: 2026-11-18
- AC: AC-DOCAI-01…AC-DOCAI-16 (`openspec/specs/document-parsing`, план `impl-document-parsing`)

## Контекст

Зріз 4 (вимога PM solomchaak/property-workflows-spec#59) додає блок «Parse a document» на сторінку рану. Менеджер рану
або адміністратор вставляє текст заявки мешканця чи кошторису підрядника, або завантажує `.txt`. AI пропонує тип
документа, телефон, опис, категорію й терміновість, або позиції й Total, а людина перевіряє, виправляє й лише тоді
зберігає. Обмеження:

- Next.js 16.4 на Vercel Hobby. Server Action приймає тіло до 1 МБ, а ми приймаємо лише текст до 20 000 символів:
  PDF, фото й скани PM винесла за межі.
- Модель безкоштовна, через OpenRouter, з власним ключем розробника. Ліміт безкоштовних моделей — 20 запитів на
  хвилину й 50 на день на акаунт; додаткові ключі ліміту не збільшують. Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати запити й навчатися на них, тому дані лише синтетичні (`555-01xx`,
  `*@example.test`).
- Відповідь моделі недетермінована, а CI має працювати без мережі й без секретів.
- Golden cases PM (#40): поріг 8 з 10, кейси 9 (відмова) і 10 (ін'єкція) обов'язкові; опис оцінюється за змістом.

## Рішення

- Нові залежності з точними версіями: `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`,
  `server-only@0.0.1`.
- Виклик іде через `generateText` + `Output.object({ schema })` (AI SDK 7; `generateObject` застарілий).
  - Схема zod (`src/lib/ai/schema.ts`) має стан `status: ok | refused`; невідоме значення дорівнює `null` («not
    found», AC-DOCAI-06).
  - Категорії, терміновість і примітки — `z.enum` зі значеннями PM.
  - Те, що можна перевірити кодом (нормалізація телефону, сума позицій проти Total, узгодженість полів із типом
    документа), перевіряється на сервері після zod, а не лише в промпті.
- Чиста функція (`src/lib/ai/parse.ts`) отримує модель параметром. Ключ читає лише `src/lib/ai/openrouter.ts` з
  `import "server-only"`; змінна — `OPENROUTER_API_KEY`, без `NEXT_PUBLIC_`. Це перевіряє `tests/ai-key.test.ts`.
- Ланцюжок моделей (лише `:free`): `google/gemma-4-31b-it:free` → `google/gemma-4-26b-a4b-it:free` →
  `nvidia/nemotron-3.5-super-vl:free`. Суддя живого eval — `nvidia/nemotron-3.5-super-vl:free`. `maxRetries: 1`,
  таймаут 45 с.
- Людина в контурі:
  - Server Action `proposeValues` спершу перевіряє `getClaims()` і право на ран (`can_parse_documents`), лише тоді
    кличе модель і повертає значення у форму, нічого не пишучи.
  - Запис робить `saveValues` після перевірки людиною: повторна валідація zod на сервері й функція Postgres з
    перевіркою права (AC-DOCAI-16).
  - Вставлений текст і відповідь моделі не зберігаються.
- Будь-який збій (немає ключа, 429, таймаут, відповідь не за схемою, помилка постачальника) показує людині «The
  assistant is not available now. Fill in the values yourself.» і порожню форму для ручного заповнення (AC-DOCAI-13).
- Перевірка якості — 10 golden cases PM:
  - офлайн-реплей записаних відповідей (`MockLanguageModelV4`) входить у `npm test` і CI;
  - живий прогін `npm run eval` розробник запускає вручну; звіт частки успіху за моделлю пишеться в `evals/reports/`.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні. SDK запускає підпроцес Claude Code (~320–342 МБ), а пакет функції Vercel
  обмежено 250 МБ; до того ж тут потрібен один виклик моделі, а не агентний цикл.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: в одному API немає валідації схемою з
  типізованими помилками й тестових моделей.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі. Перехід на платного провайдера зводиться до заміни однієї
  фабрики в `src/lib/ai/models.ts`.
- Рахувати суму кошторису моделлю — ні: PM вимагає Total «as written» і точне попередження (AC-DOCAI-08). Арифметику
  в центах робить код.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі й ліміту.
- Складніше: безкоштовна модель може зникнути або впертися в ліміт. Тоді блок переходить у стан AC-DOCAI-13, а людина
  заповнює значення вручну. Ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Коли змінюється промпт (`DOCUMENT_PROMPT_VERSION`) або схема, записи `tests/fixtures/golden/recorded.json` треба
  оновити через `RECORD=1 npm run eval`.
